## Accuracy

The model reached roughly 98% validation accuracy on ~500 clips. That is a
small dataset, so treat it as a promising figure rather than a robust one.

Validation clips each hold one neatly-positioned word, but the live device
looks at a sliding one-second window and often catches only part of a word.
Live confidence therefore runs lower than validation suggests, which is why the
detection threshold was calibrated on the board itself (see the README).
